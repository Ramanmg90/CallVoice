# CallVoice

1. Android Studio -> Open -> این پوشه
2. مدل Vosk انگلیسی را دانلود کن: https://alphacephei.com/vosk/models  (vosk-model-small-en-us-0.15)
   محتویات پوشه‌ی مدل را (am, conf, graph, ivector, ...) داخل app/src/main/assets/model/ بریز
3. Run روی گوشی (USB debugging)
4. اپ را باز کن، مجوزها را بده، "شروع سرویس"
5. شیائومی: Settings > Apps > CallVoice > Autostart روشن، Battery saver = No restrictions
6. در تماس: اسم را می‌گوید، بعد بگو "answer" یا "reject"
